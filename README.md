### 💫 À propos de moi

Je suis **Développeur Back-end spécialisé en Java et Spring Boot**, basé en Côte d'Ivoire.

J'aime concevoir et développer des applications fiables et évolutives, créer des API REST et mettre en place des architectures microservices.

Je possède également une expérience en développement Full Stack avec React ainsi qu'une expertise dans l'orchestration de flux ETL avec Apache Airflow.

- 🔭 Je travaille actuellement sur des projets basés sur **Java, Spring Boot et les microservices**.
- 🌱 J'approfondis actuellement mes connaissances en **Spring Boot, microservices, systèmes distribués et Rust**.
- 💻 Mes domaines d'expérience : **développement Back-end, API REST, React et Apache Airflow**.
- ⚙️ Je m'intéresse particulièrement à **l'architecture logicielle, la conception d'API et l'intégration de systèmes**.
- 🤝 Ouvert aux collaborations et aux projets de développement logiciel.
